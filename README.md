# ft_printf

A custom reimplementation of the standard C library function `printf`, built from scratch in C relying on some adapted functions from `libft` implementation.

## 📖 Description

`ft_printf` is a project that recreates the core behavior of the C standard library's `printf` function. The goal is to deepen understanding of:

- Variadic functions and the `va_list` mechanism
- Format string parsing
- Low-level output handling
- Modular C program design

## ⚙️ Features

`ft_printf` currently supports the following format conversions:

| Specifier | Description                          |
|-----------|---------------------------------------|
| `%c`      | Single character                      |
| `%s`      | String                                |
| `%p`      | Pointer address (hexadecimal)         |
| `%d`      | Signed decimal integer                |
| `%i`      | Signed decimal integer                |
| `%u`      | Unsigned decimal integer              |
| `%x`      | Unsigned hexadecimal (lowercase)      |
| `%X`      | Unsigned hexadecimal (uppercase)      |
| `%%`      | Literal percent sign                  |

---

## 🧠 Algorithm & Data Structure

The function performs a single left-to-right pass over the format string. Each character is either:

- printed directly, or
- if it's a `%`, treated as the start of a conversion specifier and dispatched to the appropriate handler function based on the character that follows.

Arguments are pulled from the variadic argument list (`va_list`) in the same order they're encountered in the format string, consistent with how C's variadic argument mechanism works.

Each conversion handler returns the number of characters it wrote, and these are summed to produce the function's final return value — matching the behavior of the standard `printf`, which returns the total number of characters printed.

## 📝 Instructions

### 💽 Compilation

Clone the repository and compile using the Makefile at the root of the project:

```bash
git clone <repository-url>
cd ft_printf
make
```

This will produce `libftprintf.a`, a static library you can import into your own projects.

### 🛠️ Usage

Include the header and link the library at compile time:

```c
#include "ft_printf.h"

int main(void)
{
    ft_printf("Hello, %s! You have %d new messages.\n", "world", 5);
    return (0);
}
```

```bash
cc main.c -L. -lftprintf -o program
```

### 🧹 Cleanup

```bash
make clean   # removes object files
make fclean  # removes object files and the library
make re      # full rebuild
```
